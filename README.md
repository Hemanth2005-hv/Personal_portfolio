# Personal Portfolio Website

A clean, responsive, and professional personal portfolio website built to showcase my profile, technical skills, education, certifications, and projects.

## About the Project

This portfolio website was created to present my professional background in a simple and user-friendly way. It includes important sections such as About, Skills, Education, Projects, Certifications, and Contact, making it easier for recruiters, collaborators, and visitors to learn more about me.

## Features

- Clean and professional user interface
- Fully responsive design
- Smooth in-page navigation
- Project showcase section
- Technical skills section
- Education and certifications section
- Contact information with GitHub and LinkedIn links
- Light and dark mode support

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Purpose

The purpose of this project is to build a strong online presence and professionally showcase my skills, background, and development journey.
